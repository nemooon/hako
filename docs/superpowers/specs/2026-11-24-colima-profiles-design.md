# Colima プロファイルの一覧・切り替え（issue #4）

## 目的
Colima を管理するアプリとして、複数のプロファイル（Colima の VM 1台ごとの名前）を Hako から一覧し、切り替え、起動・停止できるようにする。
想定するのは「普段は1つを使い、ときどき別のプロファイルに切り替える」使い方。
作者自身は default しか使っていない。Colima 用の UI として欠けている部分を埋めるのが目的。

## ゴール
- メニューから、プロファイルの一覧と各プロファイルの状態（実行中・停止中）が見える
- メニューとメインウィンドウから、操作対象のプロファイルを切り替えられる
- 切り替えたあとは、既存の起動・再起動・停止とコンテナ一覧が新しいプロファイルに対して動く

## やらないこと
- プロファイルの新規作成と削除（CPU・メモリ設定の #5 と一緒に考える）
- 複数のプロファイルを同時に一覧表示すること（案2として検討したが採らない）

## 失敗とみなすこと
- プロファイルが default しかないユーザーの見た目が変わる
- 切り替えたのに、Hako の表示と docker の接続先がずれる

## 検討した案
- **案1（採用）: Colima のサブメニューにプロファイル一覧を入れる。** コンパクトで、1プロファイルのユーザーには何も増えない。
- 案2: メニューの最上部に全プロファイルを並べ、それぞれにサブメニューをつける。全 VM の状態がひと目で分かるが、メニューが長くなる。複数の VM を同時に動かす使い方向けなので採らない。

切り替えの意味については、次の2つを検討した。
- **A（採用）: docker context そのものを切り替える。** ターミナルの `docker` も同じプロファイルを向く。作者は Hako の中で操作を完結させるので、ターミナル側への副作用は問題にならない。今の「docker context ＝ 操作対象」という前提にもそのまま乗れる。
- B: Hako の表示だけを切り替える。すべての docker 呼び出しに `--context` を付けて回る必要があり、ターミナルとのズレも生まれるので採らない。

## 決まった仕様
### メニュー
「Colima: 実行中／停止中」のサブメニューで、起動・再起動・停止の下に区切り線と見出し「プロファイル」を置き、プロファイルを並べる。

```
Colima: 実行中            ▸ 起動
  v0.9.1 ・ default ・ …     再起動
                            停止
                            ───────────
                            プロファイル
                            ✓ default   実行中
                              work      停止中
```

- 今の操作対象にチェックをつける。右側に状態を表示する
- 実行中のプロファイルを選んだとき: `docker context use <context>` を実行する（default は `colima`、それ以外は `colima-<name>`）
- 停止中のプロファイルを選んだとき: `colima start --profile <name>` を実行する（Colima が context も切り替える）
- `colima ls --json` の結果が1件（default だけ）なら、区切り線から下は出さない
- 起動・再起動・停止は、今どおり操作対象のプロファイルに効く

### メインウィンドウ
- ツールバーに、操作対象のプロファイルを選ぶポップアップ（`default ▾`）を置く。中身と挙動はメニューと同じ
- プロファイルが1つなら出さない

## 実装する人に任せること
- プロファイル一覧の取得方法。`colimaStatus` で既に `colima ls --json` を呼んでいるので、その結果からプロファイル一覧を `ColimaSnapshot` に持たせるのが自然
- 切り替え中の表示（既存の `busyMessage` を使う想定）
- 今のツールバーは、操作対象の VM が止まっているときは非表示になる（`MainWindow.swift` の `toolbar?.isVisible = running`）。停止中でもプロファイルを切り替えられるように、ポップアップの置き場所か、表示条件を考える
  → 計画時の判断: 停止中の画面（「Colima は停止中です」）の「Colima を起動」ボタンの下に、プロファイルを選ぶメニューを置く
- docker context が Colima 以外（例: `desktop-linux`）のときの扱い。今は default とみなしているが、その場合はどのプロファイルにもチェックをつけないほうが正確
  → 計画時の判断: チェックをつけない。どのプロファイルを選んでも切り替えを実行する
