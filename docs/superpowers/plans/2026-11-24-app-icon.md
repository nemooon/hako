# アプリアイコン作り直し（段ボール箱・Icon Composer 版） 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 段ボール箱の絵を Icon Composer のレイヤーにしたアイコンを作り、ビルド時に actool で組み込む。

**Architecture:** `Resources/Hako.svg`（箱だけ）→ `scripts/icon-layers.sh` で `Resources/Hako.icon/Assets/*.png` に書き出す → `scripts/bundle.sh` が actool で `Assets.car` と `Hako.icns` を作って .app に入れる。

**Tech Stack:** SVG、bash、`sips`、`xcrun actool`、Icon Composer の `.icon` 形式

**Spec:** `docs/superpowers/specs/2026-11-24-app-icon-design.md`

## Global Constraints

- 背景のグラデーションは #63C6D8 → #1D6A8C で、`icon.json` の `fill` に指定する
- 最低対応 OS は macOS 14.4（`LSMinimumSystemVersion`）。actool にも `--minimum-deployment-target 14.4` を渡す
- メニューバーのアイコンは変えない

## Review Focus

- 古い macOS 用の `Hako.icns` が .app に入り、`CFBundleIconFile` が残っていること → Task 2 で .app の中身を確かめる
- actool が失敗したときにビルドが止まること（壊れた .app を作らない） → `set -euo pipefail` のもとで呼ぶ
- 16 / 32px でも箱に見えること → Task 1 で actool の icns から取り出して確かめる

### Task 1: 箱のレイヤーと Hako.icon を作る

**Files:**
- Modify: `Resources/Hako.svg`（背景を外し、キャンバス全面基準に拡大）
- Create: `scripts/icon-layers.sh`
- Modify: `Resources/Hako.icon/icon.json`、`Resources/Hako.icon/Assets/`（`shippingbox.png` を削除し、`box.png` `tape.png` `label.png` を追加）

- [ ] `icon-layers.sh` は SVG のグループを 1 つずつ残した一時 SVG を作り、`sips` で 1024px の PNG にする
- [ ] actool でコンパイルし、出てきた icns の 1024 / 32 / 16px を目で確かめる。段ボールの色が抜けていないこと
- [ ] ユーザーに見せて OK をもらう
- [ ] コミットする

### Task 2: bundle.sh で actool を使う

**Files:**
- Modify: `scripts/bundle.sh`
