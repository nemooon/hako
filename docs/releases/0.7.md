# Hako 0.7

HakoとColimaを、アプリの中からアップデートできるようにしました。

## 新機能

- アップデートウィンドウを追加。HakoとColimaの新しいバージョン・変更内容・実行するコマンドを確認してから、それぞれのボタンで個別にアップデートできます。
- 開き方は3通り：アプリ名のメニュー「Hako」→「アップデートを確認…」、メニューバーの「Hako の新しいバージョン X があります」、「Colima の新しいバージョン X があります」。
- Hakoのアップデートでは、Homebrewでの更新に続けて隔離属性の削除（`xattr -dr com.apple.quarantine`）も行います。完了後は「再起動」で新しいバージョンに切り替えられます。
- Colimaのアップデート後、Colimaが動いていれば「Colima を再起動」で新しいバージョンに切り替えられます（再起動中はコンテナが止まります）。

## 注意

- アップデートウィンドウはHomebrewでインストールしている場合に使えます。
- アップデート中は、ウィンドウを閉じたりアプリを終了したりできません。
- 0.6から0.7への更新は、これまでどおりターミナルで行ってください（アップデートボタンは0.7から使えます）。

Homebrewから更新する場合：

```sh
brew update
brew upgrade --cask nemooon/tap/hako
xattr -dr com.apple.quarantine /Applications/Hako.app
```
