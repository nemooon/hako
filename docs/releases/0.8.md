# Hako 0.8

コンテナのログをアプリの中で見られるようにし、Colimaのプロファイルを切り替えられるようにしました。

## 新機能

- ログウィンドウを追加。「ログを見る」でターミナルの代わりにコンテナごとのウィンドウが開き、直近1000行から新しいログを追いかけて表示します。絞り込み・ハイライト・自動スクロールに対応。ターミナルで開くボタンもウィンドウ内に残しています。
- Colimaのプロファイルを切り替えられるようにしました。メニューのプロファイル一覧と、メインウィンドウのツールバーから選べます（Kubernetesを有効にしたプロファイルも含め、ランタイムがdockerのものが対象）。

## 改善

- アプリアイコンを段ボール箱のデザインに作り直しました。

## 修正

- メインウィンドウのサイドバーで、ポートを公開しない初期化用コンテナ（バケット作成など）の停止を「一部停止」としてオレンジ表示する問題を修正。
- アップデートウィンドウで、HakoとColimaの片方を更新すると、もう片方が「確認中」のまま残る問題を修正。
- Hakoの再起動時に隔離属性が残っていると、新しいHakoが起動せずに終了する問題を修正。外せなかった場合は再起動せずに、実行するコマンドを案内します。
- アップデートウィンドウを続けて開いたとき、「更新中」の表示が古い確認結果で上書きされる問題などを修正。

Hakoの「アップデートを確認…」から更新できます。ターミナルで更新する場合：

```sh
brew update
brew upgrade --cask nemooon/tap/hako
xattr -dr com.apple.quarantine /Applications/Hako.app
```
