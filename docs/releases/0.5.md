# Hako 0.5

メニューバーから使えるメインウィンドウを追加しました。Composeプロジェクトやコンテナの状態確認と操作を、広い画面で行えます。

## 新機能

- サイドバーでComposeプロジェクトや単体コンテナを切り替え、状態・CPU・メモリ・イメージを一覧表示。
- 名前・イメージ・サービス・プロジェクト名で検索。各列で並べ替えでき、CPU・メモリの並べ替えでは停止中を常に末尾に表示。
- リサイズできるインスペクタで、選択したコンテナの情報・公開ポート・操作を表示。
- Composeの起動・停止・再起動、エディタで開く操作をアイコンボタンから実行。
- 未使用イメージとビルドキャッシュを個別に選択して整理できる専用ウィンドウ。停止中のコンテナが参照するイメージは候補から除外し、削除前に対象件数と容量を確認。
- macOS 26以降のLiquid Glassに対応。サイドバーとインスペクタの開閉には標準アニメーションを使用。

## ショートカット

- ⌘0：メインウィンドウを開く
- ⌘1 / ⌘2：すべてのコンテナ / 単体のコンテナ
- ⌘F / ⌘R：検索 / 更新
- ⌥⌘S / ⌥⌘I：サイドバー / インスペクタを開閉
- ⌃⌘↑ / ⌃⌘↓ / ⌃⌘R：起動 / 停止 / 再起動

起動・停止・再起動は選択中のコンテナを優先し、未選択の場合はComposeプロジェクト全体を操作します。

## 改善

- Colima停止中は、ウィンドウに起動案内を表示。
- ウィンドウの位置とサイズを保存。閉じた後もメニューバーに常駐。
- 操作前に取得を始めた古い状態で、操作後の表示が上書きされる問題を修正。

対応環境：macOS 14.4以降。macOS 26未満では標準の外観で表示します。

Homebrewから更新する場合：

```sh
brew update
brew upgrade --cask nemooon/tap/hako
```
