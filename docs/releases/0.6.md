# Hako 0.6

安定性と応答性を改善しました。

## 修正

- 出力の多いコマンド（イメージの取得を伴うComposeの起動など）で、「処理中」のまま止まることがある問題を修正。
- 状態が変わらない操作の後、コンテナが停止しても通知が1回出ないことがある問題を修正。
- コンテナがunhealthyになったり回復したりしても、通知や表示が更新されないことがある問題を修正。
- 状態の取得中にコンテナが削除されると、停止中サービスのポート表示とメニューバーアイコンの警告色が一時的に消える問題を修正。
- Composeファイルのパスに `'` を含むプロジェクトを起動できない問題を修正。
- 未使用リソースの整理画面に、削除できない中間イメージが候補として並ぶ問題を修正。
- 未使用リソースの整理画面の位置が、次回起動時に画面中央へ戻る問題を修正。

## 改善

- Colimaのプロファイルを複数使っている場合、Dockerの現在のコンテキストに対応するプロファイルを表示・操作するように変更。default以外のプロファイルでは、メニューにプロファイル名を表示。
- 状態の取得を高速化（開発環境での計測で1回あたり約0.98秒→約0.76秒）。
- メニューやウィンドウを開いている間の再描画を減らし、負荷を軽減。

Homebrewから更新する場合：

```sh
brew update
brew upgrade --cask nemooon/tap/hako
```
